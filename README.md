# Airline Fare Pricing Analytics (simulated data)

Pricing analysis, automated reporting and fare forecasting on a **simulated** airline fare dataset
(20,060 bookings, 6 routes, Economy and Business). The data is generated by `01_generate_data.py`
with a fixed random seed. It is synthetic, not real airline data.

## Run order
| Step | File | What it does |
|---|---|---|
| 1 | `01_generate_data.py` | Creates `fares.csv` (includes missing values, bad fares and duplicates on purpose) |
| 2 | `02_sql_analysis.py` | Loads data into SQLite and runs SQL: GROUP BY, CTEs, RANK, moving average (window functions) |
| 3 | `03_automated_report.py` | Cleans the data (250 rows removed) and writes `pricing_report.xlsx` + charts. Re-run any time |
| 4 | `04_forecast_model.py` | Gradient boosting vs. a route+cabin average baseline |
| 5 | `05_databricks_notebook.py` | PySpark/SQL version of the route summary, for Databricks |

Install: `pip install pandas numpy scikit-learn matplotlib openpyxl`

## Results (as produced by the scripts)
- Economy fares: 0-7 days before departure average about $750; 91+ days average about $577.
- Highest revenue route: AUH-SYD, followed by AUH-JFK.
- Forecast model MAE $90.67 vs baseline $101.04 (10.3% better).

## Limitations
- Simulated data: patterns (peak months, late-booking premium) were built into the generator,
  so the model rediscovers them. A real dataset would be noisier.
- Not a production pricing system.
